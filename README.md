Набор утилит для анализа личных финансов. 
Проект предназначен для обработки данных о транзакциях, расчета статистики по категориям, дням недели и времени суток,

## Функционал

Проект предоставляет функции для анализа pandas.DataFrame с транзакциями:

1. Анализ по категориям `spending_by_category`: Группировка трат по категориям (например, "Кафе", "Транспорт") с расчетом общей суммы.
2. Анализ по дням недели `spending_by_weekday`: Группировка трат по дням недели (Понедельник, Вторник и т.д.).
3. Анализ по типу дня `spending_by_workday`: Разделение трат на "Рабочие" и "Выходные".
4. Чтение данных `read_excel_transactions`: Утилита для загрузки данных из Excel с автоматической проверкой типов данных.
5. Автоматическое сохранение: Все функции анализа автоматически сохраняют результат в файл Excel в папку проекта.

### Установка и настройка

1. Клонируйте репозитори: \
```git clone git@github.com:AlinaKhlus/work_1.git```
2. Установите зависимости:\
`poetry install`\
`poetry add --group lint flake8`\
`poetry add --group lint mypy`\
`poetry add --group lint black`\
`poetry add --group lint isort`
#### Тестирование:
В программе используются тесты функций, для их запуска используйте команду `pytest --cov`
После будет виден результат тестирования всех функций с полным отчетом о покрытии
